## Pattern Notes

- Automated closure notification from Maricopa County
- Subject line: "Air Quality Dust Permit Closed" (different from "Dust Permit Issued")
- Sent to DustPermits@, contractor contacts, and Jared@
- Contains reference to re-application process if needed
- Shorter than issuance notifications - no compliance requirements listed
- Closure may be triggered by:
  - Project completion
  - Permit expiration without renewal
  - Voluntary termination

## Workflow Trigger

This notification type can be used to:
1. Update permit status in Monday.com to "Closed"
2. Archive project files
3. Close out billing/invoicing for the project
4. Remove from active permit monitoring
