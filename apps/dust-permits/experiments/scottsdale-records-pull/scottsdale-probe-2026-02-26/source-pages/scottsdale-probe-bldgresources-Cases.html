Case Info Sheet Search

Use the Active Cases and Permits Interactive Map tool to see projects awaiting public hearings, as well as projects that have been approved and are under construction. Projects are easily identified on the interactive map and users can conveniently access the case information sheet related to a specific project. Watch this short video to learn how to use the map.

The Case Info Sheet Search is for cases that may have already been approved, denied and/or withdrawn.

Other Search Criteria


Search by Case Number

To search for a single case file, enter the full case number like 15-ZN-2015

To search for all cases of a specific type, select the case type from the dropdown list. For example DR, ZN, etc.

To search for all cases of a specific year, enter the four-digit year like 1999 or 2008.

Search by Case Name

If you are not sure of the exact case name you may enter part of the name. For example, you can enter "Scotts" to find all cases with Scottsdale in the case name, etc.

Search by Case Location

Selecting Location will bring back addresses containing words and or numbers EX "92nd" this will return all addressing with 92nd in it.

Selecting Address will return an exact address. Ex 7447 E Indian School RD Bldg 1 Unit 14

Selecting Intersection start typing the east/west street for an option to select. Ex for Oak/Hayden type in Oak, then select from dropdown option.
