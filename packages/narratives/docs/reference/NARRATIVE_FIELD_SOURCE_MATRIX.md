## Key Conclusion

For this workflow, the historical process is:

- **Mostly NOI-driven for permit/contact/core identifiers**
- **USDA-driven for soil/slopes report content**
- **AZGFD-driven for endangered appendix content**
- **Manual assembly and QA for maps, appendices, and template correctness**

The current deterministic implementation is strongest on NOI fields, and currently weak on soils/receiving/map/endangered appendix replication.
